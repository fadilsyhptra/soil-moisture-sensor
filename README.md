# 🌱 Soil Moisture Sensor (ESP8266)

This project was developed for my 2026 physics practical exam. It involves building a soil moisture sensor system using an ESP8266 to measure the moisture level in soil.

---

## 📌 Overview
The system is designed to detect how wet or dry the soil is by using a soil moisture sensor connected to an ESP8266 microcontroller. The data collected can be used for monitoring plant conditions or basic automation systems.

---

## 🎯 Objectives
- Measure soil moisture levels accurately  
- Understand the integration of sensors with microcontrollers  
- Gain hands-on experience in electronics and IoT systems  

---

## 🛠️ Technologies Used
- ESP8266  
- Capasitive Soil Moisture Sensor  
- Arduino IDE  

---

## 📚 Learning Outcomes
Through this project, I gained practical experience in:
- Working with microcontrollers  
- Interfacing sensors  
- Basic data reading and processing
